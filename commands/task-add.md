# 追加任務（/task-add）

用法：`/task-add <一句話描述>`，或不帶參數互動問。格式以 `wbs` skill 為準。

沒有 `.claude/taskmaster-data/wbs.md` → 建議先跑 `/task-init`。

## 流程

1. **先比對既有任務**：描述跟某一列重疊 → 告訴使用者是哪一列，問要不要改那一列而不是新增。
2. **範圍檢查**：描述碰到 WBS「不做」段的項目 → 明說「這在不做清單裡」，使用者確認要改範圍
   才繼續，並把那條從「不做」移掉。
3. 問（能從描述推斷的就不問）：放哪個里程碑（或新開一個）、優先、依賴、預估。
4. 編號：接該組最大序號 +1；新里程碑用新的組號。**編號永不重用**，已歸檔的也算
   （查 `wbs-archive.md`）。
5. 給使用者看新增的列，確認後寫入，同一次寫入重算現況區。

一次加很多項（例如從審查報告整理）時列成一張表一起確認，不要逐列問。
