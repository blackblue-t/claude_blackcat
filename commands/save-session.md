# Session 存檔指令

回顧本次對話，寫入 `.claude/sessions/<YYYY-MM-DD>-<主題slug>.md`。每次 session 一個新檔案，不追加到舊檔。

## 內容格式

```markdown
# <日期> — <主題>

## 做了什麼
（完成的功能/修復，一行一項）

## 確認可用的部分（附證據）
（哪些測過、怎麼測的：測試通過、手動驗證過的指令與輸出）

## 失敗的部分（和原因）★ 最重要
（試過但不行的方法、錯誤訊息、為什麼放棄。
 沒有這段，下個 session 會盲目重試已經失敗過的路。）

## 還沒試的方向
（想到但沒動手的替代方案）

## 決策與理由
（做了哪些取捨、為什麼）

## 下一步
（具體到可以直接開工的程度，含檔案路徑）
```

## 原則

- **失敗記錄不可省略**。就算全部順利，也寫「無失敗嘗試」明示
- 有 `status: active` 的計畫時，在「下一步」註明計畫檔名與 current_phase
- 空泛的「繼續開發」不算下一步；要寫「在 `src/x.py` 補 y 的錯誤處理」這種程度

## 使用時機

- 下班/收工前
- context 快滿、準備 compact 或開新 session 前
- 完成一個大階段後
