# learned：踩過的坑

一個坑一個檔案。`pitfall-gate` hook 會在 Claude 要寫入某個檔案時，比對這裡每份紀錄的 `files:`，命中就擋下那次寫入一次，把症狀、根因、避法貼出來，讀完重試同一次編輯即可通過。同一個 session 對同一個檔案只擋一次。

`files:` 寫錯或空著，這份紀錄就永遠不會觸發，等於沒寫。

格式照 `_TEMPLATE.md`。檔名 `_` 開頭的與 `README.md` 會被略過。

`files:` 的比對規則：用 shell 樣式比對「相對專案根的路徑」，`*` 會跨過 `/`。所以 `src/*.ts` 已經涵蓋 `src` 底下所有層的 `.ts`；`src/**/*.ts` 反而只比得到至少有一層子目錄的檔案。

紀錄過期或不再適用就改掉或刪掉，不要繞過閘門。整個關掉：環境變數 `PITFALL_GATE=off`。

和 `/learn` 的分工：跟特定檔案有關的教訓寫在這裡，只在碰到那些檔案時才出現；跟整個專案有關、不綁檔案的，`/learn` 寫進 CLAUDE.md。
